# OwnPaste

Paste an AI dump. Get a short version you can actually send. Nothing is uploaded.

Ask this answers: [Copying and pasting Claude responses into Slack or an email directly shifts the burden of comprehension](https://news.ycombinator.com/item?id=49372025)

- No account
- No upload
- Cap: 80 KB of text
- Cuts filler openers, closing offers, and stock Claude phrases
- Em dashes become commas or periods
- Heuristic only. Read it before you hit send.

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```
